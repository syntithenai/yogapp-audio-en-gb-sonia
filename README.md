# yogapp-audio-en-gb-sonia

Unzipped en-gb-sonia voice clips for SynthYoga Cast receivers, served at
https://syntithenai.github.io/yogapp-audio-en-gb-sonia/v1/

Published by `apps/yoga/scripts/publish-voice-files.sh` in the yogapp repo.
The phone app downloads the same clips as a zip from
https://syntithenai.github.io/yogapp-audio-en-gb-sonia/v1/en-gb-sonia.zip
